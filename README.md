# Lumière Beauty — Website Template

An elegant and responsive website template designed for beauty salons, hairdressers, makeup artists and beauty professionals.

Lumière Beauty combines minimalist design with a sophisticated aesthetic to help beauty businesses create a professional online presence.

## Features

- Elegant and modern design.
- Responsive layout for desktop, tablet and mobile.
- HTML, CSS and JavaScript.
- Spanish and English language options.
- Services and pricing sections.
- Image gallery.
- Contact information and WhatsApp links.
- Customizable text, colors, prices and business details.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Edit the HTML, CSS and JavaScript files to customize the website.
4. Replace the example business information with your own details.
